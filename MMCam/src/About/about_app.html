Motor Motion Camera (MMCam) — brief overview and maintenance notes


What is MMCam?

MMCam is a desktop application designed to control scientific cameras and motorized stages, provide live preview with overlays, and run measurement workflows tailored for optics and imaging experiments.

Key features

  • Live capture with real-time overlays and statistics
  • Support for Ximea and Moravian Instruments cameras
  • Histogram-based display mapping with manual locking
  • Motorized stage presets and reconnection via Work Station settings
  • Postprocessing: background subtraction, flat-field correction, smoothing
