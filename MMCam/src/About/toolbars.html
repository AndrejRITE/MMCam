Toolbars — Top (Horizontal) and Left (Vertical)

This page describes the controls available on the horizontal toolbar (top of the window) and on the preview-panel vertical toolbar (left). These controls provide quick access to image orientation, overlay toggles and centering helpers used during preview and setup.

Horizontal toolbar — image orientation

The horizontal toolbar contains image-orientation commands. These change how newly acquired frames are mapped to the preview and saved output. Important: orientation changes are applied to subsequent captures — they do not modify the pixel data of the frame currently displayed in the preview.

Vertical toolbar (preview panel) — overlays and centering aids

The vertical toolbar toggles visual overlays and tools used to inspect the image and help position targets. Shortcuts are available where shown.

Crosshair
Toggles a crosshair overlay centered on the preview. Useful for rough alignment and visual centering. Shortcut: C.
FWHM (Full-Width Half-Max) overlay
Shows measured FWHM contours or markers for the selected peak. Shortcut: F. The FWHM tool provides a numerical FWHM measurement in the image statistics when active.
Focus Center
Moves or highlights the focus-centering marker. This command is available only when the image analysis mode that produces the FWHM Sum is enabled (i.e., when FWHM (Sum) is checked). Shortcut: Ctrl+F.
Annulus
Toggles an annular region overlay used for ring-based analysis or for computing radial statistics. Shortcut: A.
Grid Mesh
Draws a grid mesh overlay across the preview to assist manual alignment and visual centering of spots. This overlay is located near the bottom of the vertical toolbar. Shortcut: Ctrl+G.
Circle Mesh
Shows concentric circles over the preview to aid in centering circular features. Useful when aligning round spots or for radial symmetry checks. Shortcut: Ctrl+C.

Behavior and interaction rules

  • All vertical-toolbar overlays are UI-only drawing layers — they do not modify raw image pixels saved to disk. They are intended as visual aids for alignment and measurement.
  • Focus Center is gated: it is only enabled when the FWHM Sum analysis mode is active. This prevents invoking focus-centering without the underlying measurement available.
  • Changing an overlay state does not interrupt live capture; overlays are toggled in-place and start affecting the preview immediately.
  • Orientation commands on the horizontal toolbar affect subsequent captures. To apply and confirm orientation immediately, either perform a Single Shot or restart live capture.
