Initialized Application State

After successful initialization, MMCam enters the initialized state. All controls are enabled and live image acquisition starts automatically. The preview panel is populated with live data and visual overlays describing the current acquisition and image properties.


Automatic live capture

Once the camera is initialized, MMCam immediately starts live capturing. Frames are continuously acquired and rendered in the preview panel until the user stops live view explicitly.

Live capture can be stopped and restarted using the Stop Live (L) / Start Live (L) button or the L keyboard shortcut.

Preview panel — visual overlays

The preview panel provides real-time visual feedback about the acquired image and the acquisition process. The following overlays are rendered directly on top of the image:

Image statistics (bottom-left)
Displays per-frame statistics computed from the raw image data: minimum value, maximum value, sum, mean, standard deviation, black-clipped pixel count, and saturated pixel count.
Scale bar
Shows a physical distance reference in micrometers (µm), derived from the sensor pixel size and current binning.
Image dimensions
Displays the image size in pixels and the corresponding physical size in micrometers along the horizontal and vertical axes.
FPS and frame counter (top-left)
Shows the current frames-per-second value, the running average FPS, and the total number of frames acquired since live capture started.

Camera tab — live adjustable controls

The Camera tab contains controls that affect acquisition and preview rendering:

Set Temperature [°C]
Sets the target sensor temperature. Cooling or heating is handled by the camera hardware; the measured temperature is shown in the Parameters tab.
Exposure [ms]
Integration time for each frame. Changes apply to subsequent exposures.
Binning
Pixel binning factor. Changing binning affects resolution, noise characteristics, and physical scale.
Colormap
Visualization-only setting that controls how pixel values are mapped to colors in the preview. Raw image data remains unchanged.

ROI tab — Region Of Interest

The ROI tab is used to define the Region Of Interest of the camera sensor. Restricting acquisition to a smaller sensor area can reduce the amount of transferred image data and increase frame rate on cameras that support hardware ROI.

If the selected camera does not support ROI on the hardware level, MMCam still uses the full acquired frame and crops the requested region in software. In that case, ROI affects the displayed and processed image region, but does not reduce sensor readout time.

Centrical
When checked, the ROI is adjusted symmetrically around the center of the camera sensor. In this mode, changing the ROI width or height keeps the selected region centered automatically.
X
Horizontal start position of the ROI on the sensor, expressed in pixels. This value defines the left boundary of the selected region.
Y
Vertical start position of the ROI on the sensor, expressed in pixels. This value defines the top boundary of the selected region.
Width
Width of the selected ROI in pixels.
Height
Height of the selected ROI in pixels.
Reset button
Restores the ROI to the full sensor area.

The ROI overlay is shown in the preview panel so that the selected region can be verified visually against the live image.

Parameters tab — camera state and telemetry

The Parameters tab provides a read-only view of the current camera configuration and status. Values update automatically during live capture.

Displayed parameters include camera ID, firmware version, bit depth, sensor temperature, supply voltage, power utilization, and sensor dimensions in both pixels and micrometers.

Postprocessing tab — acquisition preprocessing

The Postprocessing tab controls optional preprocessing applied to raw images when a new acquisition starts.


Background subtraction
Subtracts a reference background image from each acquired frame.
Flat-field correction
Applies gain-dependent flat-field correction using user-supplied files.
Smoothing
Optional median filtering to suppress isolated noise.
Postprocessing settings are applied when a new capture begins. If live view is already running, stop and restart live capture to apply changed postprocessing options.

Summary

In the initialized state, MMCam provides a complete live overview of the acquisition process: real-time image data, physical scaling, statistics, and camera telemetry. This state is the normal operating mode for preview, adjustment, and preparation before starting a measurement sequence.
