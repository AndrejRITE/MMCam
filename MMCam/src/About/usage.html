MMCam — Usage Overview

MMCam is an application for camera-based acquisition, live preview, image analysis, and measurement workflows involving cameras, optics, and motorized stages. This page gives a high-level overview of how the application is used and links to detailed descriptions of individual features.

Typical workflow

  1. Select and initialize a Work Station preset (camera + stages).
  2. Let the application initialize and automatically start live capture.
  3. Adjust camera parameters (temperature, exposure, binning, colormap).
  4. Use preview tools and overlays to align optics and verify signal quality.
  5. Optionally configure postprocessing (background, flat-field, smoothing).
  6. Inspect histogram and lock display range if stable contrast is required.
  7. Run measurements or save data once the setup is verified.

Work Station and initialization

The Work Station defines the physical setup: camera ID and motor assignments. After the first initialization, the Work Station dialog can be opened at any time using F2 to reconnect the camera or stages if needed.

  • Initialized Application State

Live preview and camera control

Once initialized, MMCam starts live capture automatically. The preview panel shows the image together with overlays such as statistics, scale bar, image dimensions, FPS counter, and frame number.

  • Live Capture and Preview Overlays

Toolbars and orientation controls

The application provides two toolbars: a horizontal toolbar for image orientation and a vertical toolbar for analysis and alignment tools.

  • Horizontal and Vertical Toolbars

Vertical tools — analysis and alignment

The vertical tools panel contains analysis and visualization tools used during alignment, focusing, and inspection. These tools operate on the preview and do not modify raw image data.

  • Vertical Tools Panel

Histogram and display range control

The histogram panel at the bottom of the application visualizes pixel-value distribution and controls how image intensities are mapped to the preview. Users can zoom, pan, and optionally lock a manual display range.

  • Histogram Panel

Postprocessing

Postprocessing options such as background subtraction, flat-field correction, and smoothing can be configured in advance. These settings are applied when a new capture starts and are intended to stabilize or normalize the preview and saved data.

  • Postprocessing Controls

Keyboard shortcuts

Most frequently used actions are available via keyboard shortcuts, allowing efficient operation without leaving the preview.
