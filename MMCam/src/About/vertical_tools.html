Vertical Tools Panel (Preview Tools)

The vertical tools panel (left of the preview) enables analysis and alignment overlays. Each tool has a dedicated tab on the right-side panel where you can configure its parameters. These tools do not modify raw pixel data; they provide measurement overlays and visual guidance.

Crosshair tool

The Crosshair tool draws horizontal and vertical line profiles through the preview and displays the corresponding intensity curves. It is used to quickly evaluate alignment, symmetry, gradients, and focus-related changes in the signal.

Averaging Width [px]
Defines how many neighboring rows/columns are averaged to produce the line profiles. Higher values reduce noise and stabilize the curve (at the cost of spatial specificity).
Adaptive Scaling
When enabled, the line profile curves are auto-stretched to the available plotting range. This is useful when the signal is very low: the curve becomes readable even when the absolute amplitude is small.
Crosshair profiles are intended for inspection. They do not change exposure, gain, or any image-processing parameters.

Focus Tracking tool (requires FWHM)

Focus Tracking is a focus-assist feature that operates on top of the FWHM detection logic. It is available only when FWHM is enabled, because it uses the FWHM algorithm in the background.

  • Use Focus Tracking while adjusting focus (optics position, distance, or related parameters).
  • If the tool consistently detects the spot, your current setup is typically suitable for other postprocessing algorithms as well.
  • If the tool cannot detect the spot, FWHM-based tools and spot-dependent processing will not produce meaningful results.

FWHM tool

The FWHM tool computes spot-based measurements using a Full Width at Half Maximum algorithm. It is designed for situations where a distinct spot is present in the image.

  • If no spot is detected, the tool will not display curve data or meaningful results.
  • For reliable operation, ensure the spot is sufficiently contrasted from background and not saturated.

Annulus tool

The Annulus tool defines one or more annular regions (two circles: inner radius R1 and outer radius R2) used for annulus-based measurements. You can maintain multiple annuluses; only the currently selected annulus is shown in the preview.

Create and manage annuluses

  • Press the green Plus button to add an annulus.
  • Select an annulus row in the table to make it the active (displayed) annulus.
  • Press the pink Minus button to remove the selected annulus.

Set the annulus center

  • Option 1: use the center controls in the Annulus tab (X/Y in pixels).
  • Option 2: hold Ctrl and click Left Mouse Button in the preview to set the center position.

Set inner/outer radius

  • Adjust R1 and R2 only using the radius text controls in the Annulus tab.
  • R1 must be smaller than R2 to form a valid annulus.
Multiple annuluses can be stored, but only the selected annulus is rendered in the preview at a time.

Grid Mesh tool

Grid Mesh draws a rectangular grid over the preview. It is primarily used for optics positioning and spot centering, especially when you need a stable visual reference during adjustments.

Step [px]
Grid spacing in pixels. Smaller step increases grid density; larger step reduces visual clutter.

Circle Mesh tool

Circle Mesh draws concentric circles centered in the preview to support optics positioning and spot centering. It is useful for judging radial symmetry and aligning circular features.

Step [px]
Distance between circles in pixels. Adjust to match the scale of the spot or pattern you are centering.

Practical workflow suggestions

  • Use Crosshair first to evaluate gradients and approximate alignment; enable Adaptive Scaling for weak signals.
  • Enable FWHM and Focus Tracking during focus adjustment. If the spot is not detected, fix illumination/exposure/optics first.
  • Use Grid Mesh and Circle Mesh as visual guides for precise spot centering and repeatable optics positioning.
  • Use Annulus when you need ring-based measurements; keep multiple annuluses for different radii and switch between them via the table.
