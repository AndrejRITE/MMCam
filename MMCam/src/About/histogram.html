Histogram Panel (Bottom)

The histogram panel visualizes the distribution of pixel values in the current image and controls the preview intensity mapping. You can zoom the histogram, pan it, and optionally lock a manual display range for subsequent captures.

What the histogram shows

Histogram plot
Displays the pixel-value distribution for the current frame. The plot itself is a UI tool: it does not modify raw image data, only how intensities are mapped for display.
Current view range (bottom-right)
The numeric range in the bottom-right corner shows the currently visible histogram window. When you zoom in/out or drag the histogram view, this range changes accordingly.
Manual-range indicator (*)
A star (*) in the upper-left corner of the histogram panel indicates that a manual display range has been set by the user. When the star is visible, automatic ranging is disabled for new captures.

Hover feedback: current range

When the mouse is hovering over the histogram panel, MMCam shows the current selected range directly on the histogram, making it clear what will be used for display mapping.

Zoom and pan the histogram view

You can zoom in/out and drag (pan) the histogram. This changes only what part of the histogram is currently visible and does not change the image display range by itself.

  • Zoom changes the visible portion of the histogram (for inspection).
  • Dragging pans the histogram view left/right.
  • The bottom-right numeric range updates to reflect the visible window.

Set a manual display range (locks range for next captures)

To define a manual display range, drag the left and/or right blue borders on the histogram panel. After the manual range is set, a * appears in the upper-left corner.

Behaviour rule: once a manual range is set, MMCam will keep that range for subsequent captures and will not automatically apply a new auto-range when new frames arrive. This is useful when you need stable display contrast while adjusting optics, focusing, or comparing frames.

Manual histogram range is applied for the next capture/update cycle. The currently displayed image may not be re-ranged immediately in every situation, but the next acquired frames will use the locked range.

Reset back to automatic range

To return to automatic histogram ranging, double-click the histogram panel. The * indicator disappears, and the application resumes automatic range selection for newly acquired frames.

  • Double-click histogram panel → resets to auto range
  • * disappears → confirms auto range is active again

Practical guidance

  • Use zoom + pan to inspect distribution details without changing display behaviour.
  • Use manual range when you need consistent contrast across frames (e.g., focusing or alignment).
  • Use auto range for general preview work where brightness varies between frames.
